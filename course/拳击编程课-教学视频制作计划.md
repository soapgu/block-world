# 拳击编程课教学视频制作计划

## 目标与交付物

面向 8～12 岁儿童和家长，以《编程课-拳击原理》和《编程课-拳击练习题》为唯一教学内容来源，制作两支 1920×1080、30 帧/秒的简体中文视频：

| 成片 | 长度 | 内容 |
|---|---:|---|
| 教学版 | 约 6 分 23 秒 | 游戏提问、坐标和身体位置、拳臂占格、五道题、说唱复习 |
| 说唱版 | 约 83 秒 | 92 BPM、4/4 拍，复习判断步骤和典型例题 |

脚本与分镜见 [视频脚本与分镜](video/脚本与分镜.md)。视频文件与 SRT 字幕输出到 `video/out/`。

## 分步骤制作

1. **锁定教学内容**：固定身体位于 `(5,3)、(6,3)、(5,4)、(6,4)`；拳臂从起点向下延伸三格。五题答案依次为打中、打空、打空、打中、打空。
2. **写脚本与分镜**：每段标明时间、画面文字、动画和旁白；五道题先给六秒思考时间，后逐格揭晓。
3. **准备画面**：录制现有拳击原型作为开场；复用 `assets/boxing-course` 中的题目图；蓝色表示身体，橙色表示拳臂，绿色表示重叠。
4. **制作动画**：Remotion 渲染九乘九棋盘、坐标标记、拳臂延伸、题目倒计时、答案和逐句字幕。
5. **制作教学音频**：普通话旁白配轻量背景音乐；只在答案揭晓时播放命中或打空音效。
6. **制作说唱音频**：原创 32 小节歌词和 92 BPM 节拍，逐小节安排普通话节奏朗读，检查数字和关键术语的发音。
7. **剪辑导出**：独立导出教学版和说唱版 MP4、两份 SRT 字幕；教学版尾部包含完整说唱版。
8. **核对成片**：检查坐标、拳臂长度、五题结果、答题时答案不提前显示、字幕可读和音画同步。

## 教学准确性

起点位于身体上方时，本课固定身体位置和拳臂长度对应的条件为 `5 ≤ x ≤ 6` 且 `5 ≤ y ≤ 7`。原讲义把 y 上界写成 6，漏掉了 `(6,7)` 这样的命中情况；详情见 [讲义勘误](video/讲义勘误.md)。游戏原型真正使用的是两个矩形区域的重叠检测；视频结尾明确回到“身体区域与拳臂区域有重叠就命中”的通用原理。

## 复现方式

在 `course/video` 中安装 `package.json` 的依赖，运行 `python3 tools/build_audio.py` 生成系统语音、节拍和字幕，运行 `node tools/capture_game.mjs` 从本地原型录制开场片段，再运行 `npm run render:lesson` 和 `npm run render:rap`。macOS 系统语音需要可用的普通话语音；Remotion 渲染需要 Chrome。

## 验收清单

- [x] 教学版与说唱版均通过完整解码，规格为 1920×1080、30 fps，并含音轨。
- [x] 身体四格、拳臂四格和五题答案经过程序化核对；讲义中的范围错误已另列勘误。
- [x] 练习题思考阶段没有提前显示答案；答案语音均在第 6.5 秒后开始。
- [ ] 请人工试听字幕与人声同步程度，确认数字、坐标和“打中／打空”读音清楚。
- [ ] 观看者能用“对准、够到、重叠”解释至少一道题。
