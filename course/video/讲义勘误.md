# 拳击编程课讲义勘误

原讲义和练习题写成“`5 ≤ 拳头 x ≤ 6`，而且 `5 ≤ 拳头 y ≤ 6`”。按同一份讲义规定，身体占 `(5,3)、(6,3)、(5,4)、(6,4)`；拳臂连同起点向下占四格。若起点为 `(6,7)`，拳臂占 `(6,7)、(6,6)、(6,5)、(6,4)`，与身体在 `(6,4)` 重叠。因此在“起点位于身体上方”的前提下，正确的固定场景范围是：

> `5 ≤ x ≤ 6`，且 `5 ≤ y ≤ 7`。

五道现有练习题的答案不变。第 4 题 `(5,6)` 的拳臂占 `(5,6)、(5,5)、(5,4)、(5,3)`，与身体在 `(5,4)` 和 `(5,3)` 重叠；原讲义中“末端刚好到达 y=4”并不准确。视频改用“拳臂经过身体左边一列”解释。

此文仅记录并修正视频中的讲解；原讲义、练习题、配图和游戏代码未修改。通用判定仍以区域是否重叠为准。
