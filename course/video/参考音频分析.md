# 参考音频分析

## 来源与取样

- 参考作品：[万有音律《为什么比萨斜塔到现在还没有倒？》](https://www.douyin.com/video/7671251685276257588)，页面显示总长约 4 分 02 秒。
- 通过 macOS ScreenCaptureKit 仅捕获 Chrome 的应用音频；先做短录音测试，再将播放位置移至约 `00:18`，录制后续片段。录制启动与网页播放没有逐帧同步，因此本次样本对应视频**约 `00:20–01:24`**，时间范围是估计值。
- 录音保存在 [`out/reference-audio.wav`](out/reference-audio.wav)，仅供分析，不进入成片。文件长 **63.76 秒**，48 kHz、双声道。音量测量约为平均 **−17.2 dBFS**、峰值 **−3.6 dBFS**；全段均有音频信号。短录音测试确认了可捕获声音，但这些数值本身不能证明人声一定清晰。

## 尚不能确认的听感细节

当前分析环境无法把录音作为可直接听辨的输入。2026-09-28 重新完成 arkcli SSO 登录后，使用 `arkcli +understand asr` 提交压缩后的录音样本，但当前 Agent Plan 返回“所请求模型不支持 Agent Plan 功能”；已有的按量 Profile 未设置默认文本 Endpoint，实时查询也显示可用文本 Endpoint 数量为 **0**。因此本次没有得到模型转写或声学描述，不能把音量和频谱测量冒充听辨结果。

**女声的具体音色与自然度、唱与说各占多少、旋律如何重复、歌词每秒密度、确切乐器与鼓型**仍未得到可靠核实。用户希望以好听的女声演唱，这是新版歌曲的创作要求，不应写成对参考作品的已验证结论。进入歌曲创作前，需由能听到录音的人完整听一遍样本，或在配置支持音频理解的可调用 Endpoint 后补充这些判断。

## 可借鉴的制作方向

以下是依据已核实信息提出的**创作推断**，并非对原曲的逐项还原：

1. 用一个有连续律动、适合清晰叙事的中速节拍作起点；约 90 BPM 可作为试作速度，最终按新旋律调整。
2. 每个画面只突出当前一句歌词和一个核心词，配合坐标棋盘与拳臂动画，让孩子能跟上“对准、够到、重叠”的判断过程。
3. 保持新歌的旋律、歌词、配器和录音原创；参考作品的录音只用于分析，不采样、不混入最终视频。
