# 拳击编程课：教学版脚本与分镜

规格：1920×1080，30 fps，普通话；主课 5 分钟，结尾接 83 秒说唱复习。

## 逐段脚本

### 00:00–00:18｜一拳为什么会打中？

- 画面：游戏实录与主标题；呈现命中、打空疑问。
- 屏幕文字：看起来靠得很近，也可能打空。
- 旁白：欢迎来到方块世界的拳击擂台！同样出一拳，有时打中，有时却打空。计算机究竟怎么判断呢？

### 00:18–00:35｜先观察游戏

- 画面：展示现有 v1 原型游戏实录和操作提示。
- 屏幕文字：方向键移动 · A 左拳 · D 右拳
- 旁白：先看一小段游戏。机器人移动、出拳，打中时对手少一格生命。今天我们要破解这一拳背后的数学秘密。

### 00:35–01:00｜给格子一个门牌号

- 画面：九乘九棋盘出现；标出原点、x 与 y 方向。
- 屏幕文字：原点 (0,0)  ·  x 向右  ·  y 向上
- 旁白：每个格子都有一个门牌号，叫坐标。左下角是零、零。横坐标表示从左往右第几列，纵坐标表示从下往上第几排。

### 01:00–01:25｜身体占了哪四格？

- 画面：蓝色身体四格依次点亮。
- 屏幕文字：(5,3)  (6,3)  (5,4)  (6,4)
- 旁白：蓝色身体占两列、两排，总共四格。横坐标是五和六，纵坐标是三和四。判断命中，就要知道拳臂会不会碰到这四格。

### 01:25–01:55｜拳头不只是一个点

- 画面：从 (6,5) 向下逐格延伸橙色拳臂。
- 屏幕文字：起点 (6,5) → (6,4) → (6,3) → (6,2)
- 旁白：拳头从六、五出发，拳臂再向下伸出三格。连同起点，一共占四格。我们让橙色拳臂一格一格地走下去。

### 01:55–02:20｜有重叠，就打中

- 画面：(6,5) 的拳臂与身体重叠，重叠格变绿。
- 屏幕文字：(6,5)：拳臂与身体有重叠格
- 旁白：看，拳臂经过六、四和六、三。这两个格子也属于蓝色身体。橙色和蓝色重叠，变成绿色，这一拳打中了。

### 02:20–02:40｜横向没对准

- 画面：(8,6) 的拳臂从身体右侧经过。
- 屏幕文字：(8,6)：够得到，却从旁边经过
- 旁白：把拳头移到八、六。纵向虽然够得到，横坐标八却不在身体的两列里。拳臂从旁边经过，所以打空。

### 02:40–03:00｜纵向够不到

- 画面：(6,8) 的拳臂停在身体上方。
- 屏幕文字：(6,8)：对准了，却离得太远
- 旁白：再看六、八。横向已经对准，但拳臂最远只到纵坐标五，碰不到身体的最高一排四，所以也打空。

### 03:00–03:25｜先对准，再够到

- 画面：并列展示横坐标和纵坐标的固定场景判断条件。
- 屏幕文字：起点在身体上方；x：5 ≤ x ≤ 6；y：5 ≤ y ≤ 7
- 旁白：在这个身体固定、拳臂向下伸三格的场景里，起点位于身体上方时，横坐标是五或六，纵坐标可以是五、六或七。比如六、七，拳臂末端仍会碰到身体。两个条件要同时成立。

### 03:25–03:35｜轮到你来判断

- 画面：展示三步判断方法。
- 屏幕文字：先看 x，再看 y，最后找重叠格
- 旁白：现在轮到你。每题先自己想一想，答案会在倒数后出现。

### 03:35–03:48｜第 1 题

- 画面：先展示拳头起点与倒计时；六秒后逐格延伸拳臂并揭晓答案。
- 屏幕文字：拳头起点 (6,5)
- 旁白：横坐标对准，纵坐标够到。拳臂与身体重叠，打中！

### 03:48–04:01｜第 2 题

- 画面：先展示拳头起点与倒计时；六秒后逐格延伸拳臂并揭晓答案。
- 屏幕文字：拳头起点 (8,6)
- 旁白：横坐标八偏到右边，虽然够得到，仍然打空。

### 04:01–04:14｜第 3 题

- 画面：先展示拳头起点与倒计时；六秒后逐格延伸拳臂并揭晓答案。
- 屏幕文字：拳头起点 (6,8)
- 旁白：横向对准了，但纵向太远，拳臂够不到，打空。

### 04:14–04:27｜第 4 题

- 画面：先展示拳头起点与倒计时；六秒后逐格延伸拳臂并揭晓答案。
- 屏幕文字：拳头起点 (5,6)
- 旁白：横向对准，拳臂经过身体左边一列，打中！

### 04:27–04:40｜第 5 题

- 画面：先展示拳头起点与倒计时；六秒后逐格延伸拳臂并揭晓答案。
- 屏幕文字：拳头起点 (7,5)
- 旁白：只差一列也没有重叠，所以打空。

### 04:40–05:00｜真正的规则：区域重叠

- 画面：身体和拳臂区域同时高亮，提示通用的重叠规则。
- 屏幕文字：身体区域 ∩ 拳臂区域 ≠ 空 → 命中
- 旁白：记住：先看有没有对准，再看够不够得到。今天的数字只属于这个固定场景；机器人换了位置，通用办法仍是检查两个区域有没有重叠。接下来，用一段说唱把知识点记牢！

## 内容核对

- 身体四格：`(5,3)、(6,3)、(5,4)、(6,4)`。
- 拳臂：从起点向下延伸三格，连同起点占四格。
- 五题答案：`(6,5)` 打中，`(8,6)` 打空，`(6,8)` 打空，`(5,6)` 打中，`(7,5)` 打空。
- 起点位于身体上方时，正确的固定场景条件是 `5 ≤ x ≤ 6` 且 `5 ≤ y ≤ 7`；原讲义漏掉了 y=7。
- 通用原理是两片区域是否重叠。
