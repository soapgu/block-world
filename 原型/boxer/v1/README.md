# 机器人拳击 · 俯视复刻 v1（原型）

> **注意：本目录为原型中间过程，非正式发布。** 用于复刻 90 年代国产掌机内置的「拳击对战」（俗称「机器人拳击」）小游戏。

## 运行方式

直接用浏览器打开本目录下的 `index.html` 即可游玩（推荐 Chrome / Edge / Firefox）。

## 操作

| 按键 | 动作 |
|---|---|
| `←` / `→` | 左右移动（按住持续走） |
| `↑` | 向前（靠近对手） |
| `↓` | 向后（远离对手） |
| `A` | **出左拳** |
| `D` | **出右拳** |
| `回车` | 标题画面开始 / KO 后再来一局 |

## v1 功能

- 俯视/顶视视角，单色点阵 LCD 风格
- **可移动**：拳击手可在擂台内左右/前后移动，靠近对手才能打到（不能穿出擂台、不能互相穿过）
- 拳击手：完整形态 **6 格方块**（身体 2×2 四格 + 双手各一格）；**静止时只显示 4 格身体**，出拳时只出现**出拳的那只手**并前伸 3 格（另一只手不显示，不会左右手同时出拳）
- 单人打电脑，双方各 **5 格生命**（格子血条，被打中掉一格）
- **命中判定**：出拳的拳头必须**够到**对方身体才算命中（AABB 碰撞），距离不够时挥空无效果；够到后命中并打断对方出拳，同帧互中则互换
- 出拳节奏：前摇 → 命中窗口 → 收拳 → 冷却；冷却结束才能再出拳（`A` 左拳 / `D` 右拳，自行选择）
- 电脑 AI：会移动走位、靠近玩家，够得着才出拳；玩家出拳后 25% 概率反打（够得着时）
- 完整流程：标题 → 移动对打 → KO 结算 → 再来一局
